# NothiSetu — Tender Package Studio

NothiSetu is a bilingual, browser-only workspace for turning tender requirements and local PDF files into a checked, correctly ordered submission package.

The application is being built for the AI DevFest 2026 Vibe Coding Contest. All tender documents stay on the user's device; the deployed site contains no application backend, database, or online document storage.

## Planned core workflow

1. Load `requirements.json` and display tender details in requirement order.
2. Upload and inspect PDFs locally in the browser.
3. Match one file to one requirement and enter required expiry dates.
4. Detect exact duplicate content and continuously calculate document statuses.
5. Generate and download a cover-led, ordered PDF package with safe page footers.
6. Complete the whole workflow in English or Bangla.

Implementation details, completed features, known issues, AI tools, and the most useful prompt will be updated as the project is built.
